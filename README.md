# mindmoney.work

Независимая история клиента Mind Money. React + Vite + TypeScript.
Текущая версия — одна страница: личная история, события, вопросы и информация
о документах по запросу. Публичного каталога клиентских документов нет.

## Локальный запуск

```sh
npm ci
npm run dev -- --port 5173
```

Открыть http://127.0.0.1:5173/ . Остановить сервер: Ctrl+C.

```sh
npm run build
npm run preview
```

Статическая сборка — `dist/`. Домен не подключён, сайт не опубликован.
Для черновика сохранён запрет индексации в `index.html` и `public/robots.txt`.

## Структура

- `src/content.ts` — события и проверенные ссылки на публичные источники.
- `src/main.tsx` — одностраничная история, якорная навигация, информация о запросах.
- `src/style.css` — сине-белая палитра и адаптивная вёрстка.
- `public/mind-money-logo.svg` — публичный логотип брокера для идентификации
  предмета истории. Получен с https://static.tildacdn.com/tild3832-6662-4165-a265-366161326331/logo_1.svg .

У логотипа и в подвале явно указано, что сайт независимый и не связан с брокером.
Ссылки старой версии `#/…` ведут к соответствующим блокам одной страницы.

## Контент

Личные эпизоды основаны на рассказе автора. Оригиналы клиентских документов
для проверки пока не предоставлены. Документы не публикуются; перед передачей
по запросу требуется защита данных третьих лиц. Ссылка внизу раскрывает информацию
о предоставлении документов, но не имитирует отправку запроса. Контакт для запросов и коллективного письма: https://t.me/makemitos (подтверждён автором).

Дата первичной проверки публичных источников — 19 ноября 2026 года. Переработка
оформления — 21 ноября 2026 года. Ссылки на CySEC, «Коммерсантъ» и уведомление
Mind Money стоят непосредственно в рассказе. Полный текст PDF CySEC автоматически
загрузить не удалось; основания атрибутированы уведомлению самой компании.
Статус лицензии описан на дату исторического решения, без заявления о текущем статусе.
Обвинения не представлены как доказанная вина. Участие акционеров в предполагаемых
незаконных операциях не утверждается. Итоговый ущерб не рассчитан.

До публикации: проверить личные документы, сверить
оригинал CySEC и актуальные сведения, согласовать окончательный текст. Затем
добавить canonical и метаданные для mindmoney.work и снять запрет индексации.

Внешний шрифт Golos Text загружается через Google Fonts, резервный — Arial.
